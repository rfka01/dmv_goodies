# Images

`GOODIES.IMG` – 360 KB disk image for the NCR Decision Mate V (MAME driver `dmv`) with the ready-to-run programs, without sources · 360-KB-Diskettenabbild für die NCR Decision Mate V mit den fertigen Programmen, ohne Quellen:

| File | |
|---|---|
| `DMVDEMO.COM`, `DMVDEMO.TXT` | graphics demo · Grafikdemo |
| `KITT.PIC`, `KITT.TXT` | photo for screen 12 (CC BY-SA 4.0) · Foto für Bild 12 |
| `DMVRACE.COM`, `DMVRACE.TXT` | processor race · Prozessor-Rennen |
| `ECODRIVE.COM`, `ECODRIVE.TXT` | RAM disk in the red/blue video memory · RAM-Disk im Rot/Blau-Bildspeicher |
| `MOUSETST.COM`, `MOUSETST.TXT` | test for the K806 mouse adapter · Test für den Maus-Adapter K806 |
| `DMVKERM.COM`, `DMVKERM.TXT` | Kermit and terminal · Kermit und Terminal |

The `.TXT` files are the German descriptions (DOS text, CRLF). · Die `.TXT`-Dateien sind die deutschen Beschreibungen.

`DMVKERM.IMG` – separate DMVKERM disk with DMVKERM 1.1 (same as on `GOODIES.IMG`) and Kermit-MS 2.32 for the other end · eigene DMVKERM-Diskette mit DMVKERM 1.1 (wie auf `GOODIES.IMG`) und Kermit-MS 2.32 für die Gegenseite:

| File | |
|---|---|
| `DMVKERM.COM` | Kermit and terminal for the DMV · Kermit und Terminal für die DMV |
| `DMVKERM.TXT` | description (German) · Beschreibung |
| `DMVKERM.INI` | sample start-up settings · Beispiel-Starteinstellungen |
| `KERMIBM.EXE` | original Kermit-MS 2.32/A (Columbia University) for IBM-compatible PCs · für IBM-kompatible PCs |
| `KERMIT.LIC` | licenses · Lizenzen |

| File | |
|---|---|
| `DRUCKER.BAT` | list of the printers · Liste der Drucker |

| `*FONT.PRN`, `*FNT.PRN`, `*GRF.PRN`, `MX80*.PRN` | per printer · je Drucker |
| `LIESMICH.TXT` | description (German) · Beschreibung |
