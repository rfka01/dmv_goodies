KERMIT - MS-DOS Kermit 3.16 fuer die NCR Decision Mate V
=========================================================

Terminal (VT52, VT100, VT102, VT220, VT320) und Dateiuebertragung nach
dem Kermit-Protokoll ueber die seriellen Module K211, K212 und K801 der
DMV. Grundlage ist MS-DOS Kermit 3.16 der Columbia University
(Quelltext: github.com/hackerb9/mskermit), angepasst an die DMV.

Auf der Diskette
----------------
  KERMIT.EXE    Kermit fuer die DMV
  KERMIBM.EXE   MS-Kermit 3.16 fuer IBM-kompatible PCs (ohne Netzwerk,
                mit JWasm neu uebersetzt, mit UPX gepackt), fuer die
                Gegenseite
  MSKERMIT.INI  Voreinstellungen, die beide beim Start lesen
  KERMIT.TXT    diese Beschreibung
  KERMIT.LIC    Lizenz von MS-DOS Kermit (3-Klausel-BSD)

Voraussetzungen
---------------
  - DMV mit 8088/V20-Karte (K230, K231 oder K235)
  - MS-DOS 3.30 (DMV-Port), NCR MS-DOS 2.11 oder DR-DOS 3.41 (DMV-Port)
  - mindestens 256 KB Speicher. Mit 256 KB bleiben unter DOS 3.30 rund
    14 KB frei, unter DR-DOS 3.41 rund 1,5 KB: es gibt dann keinen
    Rueckblickspeicher fuer den Bildschirm, und PUSH/RUN (DOS aus Kermit
    heraus) gehen nicht.
  - ein serielles Modul: K211 (Modem), K212 (Drucker), K213 (Plotter)
    mit 2651 oder K801 mit 2661

Serielle Module
---------------
Kermit sucht die Module beim Start selbst, in der Reihenfolge der
IFSEL-Haelften 1A (70h), 1B (78h), 0A (60h), 0B (68h), 2A (30h),
2B (38h), 3A (B0h), 3B (B8h). Das erste gefundene ist PORT 1 (COM1),
das zweite PORT 2 (COM2). SHOW COMMUNICATIONS bzw. SHOW MODEM zeigen
Modul, Adresse und Interrupt.

Mit der K235 (8088 mit Interruptcontroller) findet Kermit den Interrupt
des Moduls selbst (die DIP-Schalter der K235 legen ihn fest) und
empfaengt per Interrupt. Ohne Interruptcontroller (K230/K231) oder wenn
kein Interrupt ankommt, fragt Kermit das Modul ab (Polling). Der 2651
haelt nur zwei Zeichen; waehrend DOS auf den Bildschirm oder die
Diskette schreibt, kann Kermit nicht nachsehen. Ohne Interrupt daher
beim Empfangen hoechstens 2400 Baud waehlen (SET SPEED 2400); Senden
geht auch mit 9600 Baud. SHOW MODEM zeigt, ob Kermit einen Interrupt
gefunden hat ("polled" heisst: keiner).

Geschwindigkeiten: 50 bis 19200 Baud (SET SPEED). Kermit uebernimmt
beim Start die Geschwindigkeit, auf die das Modul gerade eingestellt
ist.

Tasten
------
  CTRL-CLR     Fluchttaste im Terminalbetrieb (CONNECT). Danach:
                 C   zurueck zum Prompt MS-Kermit>
                 ?   Liste aller Befehle nach der Fluchttaste
                 B   Break senden
                 H   auflegen (DTR weg)
                 S   Status
  CLR          sendet DEL
  Pfeiltasten  wie die Cursortasten eines VT102
  F1 ... F10   wie F1 ... F10 der IBM-Tastatur (Kermit belegt F1-F4
               im VT-Betrieb mit PF1-PF4, siehe SHOW KEY)
  Umlaute      werden als Zeichen des PC-Zeichensatzes (CP437)
               uebergeben; mit SET TERMINAL CHARACTER-SET GERMAN
               sendet und zeigt Kermit die deutschen 7-Bit-Zeichen
               (DIN 66003) wie ein VT102 mit deutschem Zeichensatz.
SET KEY und SHOW KEY arbeiten wie bei MS-Kermit; die Tasten der DMV
erscheinen dort mit den Codes der entsprechenden IBM-Tasten.

Bildschirm
----------
Kermit schreibt ueber die DOS-Konsole und benutzt nur das, was alle
drei DOS-Fassungen der DMV koennen: Cursor setzen, Zeile loeschen,
Bild loeschen, normal/invers/blinkend/halbhell. Unterstreichen und
Farbe zeigt die DMV nicht; unterstrichene Zeichen erscheinen halbhell.
Die unterste Zeile ist im Terminalbetrieb die Statuszeile (abschalten
mit SET MODE-LINE OFF).

Dateien und Zeichensaetze
-------------------------
Die DMV kennt keine Codepages. Kermit speichert empfangene Dateien
deshalb genau so, wie sie ankommen, und sendet sie ebenso
(SET TRANSFER CHARACTER-SET kennt nur TRANSPARENT). Fuer Programme
und andere Binaerdateien SET FILE TYPE BINARY waehlen.

Erste Schritte
--------------
  A>KERMIT
  MS-Kermit>SET SPEED 9600
  MS-Kermit>CONNECT                 (anmelden, auf der Gegenseite Kermit
                                     starten und SERVER eingeben)
  CTRL-CLR, C                       (zurueck zur DMV)
  MS-Kermit>GET datei.txt           (vom Server holen)
  MS-Kermit>SEND brief.txt          (zum Server schicken)
  MS-Kermit>FINISH                  (Server beenden)
  MS-Kermit>EXIT

Ein "?" an jeder Stelle eines Befehls zeigt, was dort stehen kann.
INTRO gibt eine kurze Einfuehrung, HELP eine Uebersicht.

Was gegenueber MS-Kermit 3.16 fehlt
-----------------------------------
Damit Kermit in 256 KB passt, enthaelt die DMV-Fassung nicht:
TCP/IP und andere Netze, Tektronix-Grafik, die Terminals Heath-19,
Prime PT200, Data General D217/D463/D470, Wyse-50 und Honeywell
VIP7809, Codepages und Zeichensatzumsetzung fuer Dateien, seltene
Terminal-Zeichensaetze (Hebraeisch, Kyrillisch, Japanisch, HP-Roman8,
Latin-2; sie erscheinen als ASCII), 132 Spalten, die Skriptfunktionen
\f...(), die Berichte DECRQSS, DECRQTSR und DECRQPSR, APC-Makros,
Rueckblick in EMS/XMS und die langen Hilfeseiten (sie stehen unten in
dieser Datei).
Der Servermodus (SERVER) ist enthalten.

Kurz auf Englisch
-----------------
KERMIT.EXE is MS-DOS Kermit 3.16 for the NCR Decision Mate V with the
serial modules K211/K212/K213 (2651) and K801 (2661). It runs under the
DMV ports of MS-DOS 3.30, NCR MS-DOS 2.11 and DR-DOS 3.41 with at least
256 KB. It finds the modules and (with a K235) their interrupt by
itself, and polls otherwise (then receive at 2400 Baud at most).
The escape key in CONNECT mode is CTRL-CLR (then C to return, ? for
help). Files are stored as they arrive; the DMV has no code pages.
Not included: networks, Tektronix graphics,
Heath-19, PT200, DG, Wyse and Honeywell emulations, file character-set
translation, rare terminal character sets, 132 columns, the \f...()
script functions, DECRQSS/DECRQTSR/DECRQPSR reports, APC macros,
EMS/XMS rollback and the long help pages (appended below).
KERMIBM.EXE is MS-Kermit 3.16 for IBM-compatible PCs (without networks,
rebuilt with JWasm).

Stand: getestet in einem Emulator-Pruefstand der DMV unter MS-DOS 3.30
(K211 mit K235 bei 9600 Baud, ohne Interrupt bei 2400 Baud; 256 und
512 KB) und unter DR-DOS 3.41 (256 KB), jeweils mit Dateiuebertragung
in beide Richtungen gegen C-Kermit. Unter NCR MS-DOS 2.11, mit der
K801, in MAME und auf echter Hardware noch nicht erprobt.

========================================================================
SET TERMINAL COLOR ?
========================================================================
  Set Term Color  value, value, value, ...
   0 no-snow mode on an IBM CGA and white on black
   1 for high intensity foreground
  10 for fast CGA screen updating (may cause snow)
  20 to restore normal colors after ESC [ 0 m
  Foreground color (30-37) = 30 + sum of colors
  Background color (40-47) = 40 + sum of colors
    where colors are  1 = red, 2 = green, 4 = blue
  Ex: 0, 1, 37, 44   IBM CGA(0), bright(1) white(37) chars on a blue(44) field
  Attributes are applied in order of appearance.

========================================================================
SET KEY ? (key)
========================================================================
 Enter key's identification as a character
  or as its numerical equivalent \{b##} of ascii
  or as its scan code \{b##}
  or as SCAN followed by its scan code
    where b is O for octal, X for hex, or D for decimal (default).
    Braces {} are optional.
    Follow the identification with the new definition.
 or CLEAR to restore initial key settings
 or ON (default) for Bios i/o or OFF to use DOS i/o
 or LK to use the DEC LK250 keyboard.

========================================================================
SET KEY key ? (definition)
========================================================================
 Enter either  \Kverb  for a Kermit action verb
 or a replacement string  (single byte binary numbers are \{b##})
 or push Return to undefine a key, ^C to retain current definition.
 Braces {} are optional, and strings maybe enclosed in them.
 Strings may not begin with the character combinations of  \k  or  \{k
    (start with a { brace instead).

 Verbs are as follows. Keys (arrows and keypad):
   uparr, dnarr, lfarr, rtarr, kpminus, kpcoma, kpdot, kpenter,
   Gold (same as PF1), PF1, PF2, PF3, PF4, kp0, ... kp9
   decFind, decInsert, decRemove, decSelect, decPrev, decNext
   decF6, ...decF14, decHelp, decDO, decF17, ...decF20
   Compose (same as dgSPCL)
   User Definable Keys udkF6, ...udkF20
   Data General dgC1..dgC4, dgF1..dgF15, dgSF1..dgSf15,
   dgPoint, dgSPCL, dgNC
   Wyse-50 function keys wyseF1..wyseF16, wyseSF1..wyseSF16
 Kermit screen control and actions:
   upscn, dnscn, homscn, endscn, upone, dnone (vertical scrolling),
   lfpage, lfone, rtpage, rtone (horizontal scrolling)
   logoff, logon, termtype, reset, holdscrn, modeline, break, debug,
   lbreak, nethold, nextsession, prtscn, dump, hangup, null (send one),
   session1, ..session6 (selects Telnet session number 1..6)
